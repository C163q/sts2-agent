## 第 3 阶段

- ToolSpec 集中 43 个公开工具的名称、描述、schema、领域解析、预设、reader／投影绑定、分类、副作用、许可、事件记录及 annotations。目录、handler、公共分类与生产 reader 分派从同一登记派生。
- 显式模块／函数绑定在消费处解析，不按输出字段推断 reader，也不让领域分类反向导入总装配。
- normalize_request 独立输出原生参数、投影参数和执行规则；类型／范围／枚举／必填等错误指出参数。inspect_selection 的 view_upgrades、set_divination_tool 与截图的执行维度独立验证。
- 筛选省略／null 取全部，[] 为空，保留原顺序、去重及合并缺失值；遗物提示引用改用未筛选下标。共用帮助裁剪，保留对象前缀、精确来源与卡牌身份的领域差别。
- CLI 目录及已有浏览／战斗对象参数接入登记，保留原有命令选项、默认值、raw 与完整观察范围。

固定基线的 228 个 MCP、51 个 CLI 用例继续回放；原始样本未重生成。明确允许的断言差异只有未知参数诊断文字、一个筛选遗物样本的提示下标。本阶段完整 Python 检查为 559 项通过，起始基线为 552 项通过。新增登记／参数检查覆盖全部工具、整数边界与 bool 混淆、可选筛选、独立执行维度及与原生 RecordedActions 的对照；原生代码未变。

本机日志保留于忽略目录 `.tmp/2026-11-04-refactor-stages-3-4/`。首次回归暴露旧 null／提示下标断言和一个旧 ui_details 导入；已按确认的新契约更新断言并保留兼容导入。没有以这些测试载荷冒充游戏实测。

## 第 4 阶段

- GameTools 收敛为公开 facade；GameSession.execute 统一锁、控制器、发送、响应校验、投影与许可。PermissionState 用 token／generation 记录许可，进入等待前捕获 ticket，不向模型公开。
- 所有本地参数拒绝保留已有许可；所有纯读的明确原生拒绝可保留许可。页面操作、状态过期、坏响应、控制器冲突、异常、超时或取消不恢复；失败不生成许可。
- 执行证据独立于公开 JSON；只有登记为已核实的 play_card 未提交且 UI 未改变拒绝可续接旧许可。其他动作不借用该保证，原生缺失证据保持保守。
- 相同 token 的后续读取有不同许可代次；排队动作不能借用。取消等待请求会撤销许可，并阻止在途响应再次授权。完整校验和公开投影均成功后才能发布新许可。
- 动作／页面的 screenshot_unavailable 使用未知结果及先观察提示；截图自身保留窗口错误语义。原生媒体需求暂未接入，不将失败误称为未执行，也不自动刷新或重试。
- CLI 与 MCP 共用动态副作用判定；标准库入口及原有默认值／raw／完整观察范围保留。

本轮独立审查未发现 Critical／Important，指出一项低影响的 CLI 动态分类不一致：对 inspect_selection --view-upgrades 注入 screenshot_unavailable，文件错误分支未获得请求参数，仅使用静态 read 分类。当前原生 selection 详情不携带占卜媒体，尚无自然游戏触发证据。本轮将其作为共用错误分类的契约缺口修复：ToolSpec.effect_for 统一动态判定，并在文件错误路径传入原生参数；新增启用／关闭／省略升级参数的失败断言，已验证失败后修复通过，没有扩大原生范围。
