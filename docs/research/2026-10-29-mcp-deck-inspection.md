## 范围与契约

基于已加载并验证的 Mod 0.10.0，新增 `inspect_deck`、`close_card_view`，MCP server 升至 0.7.0，固定公开九个工具。游戏页面、参数和 JSON 规则沿用 [牌组查看与关闭](../development/deck-inspection.md)。本次同步将 Mod 的关闭范围扩大为原生牌组、抽牌堆、弃牌堆和消耗牌堆查看页；只关顶层卡牌页，保留下面的地图。不实现动态工具列表，不修改全局客户端配置。

`inspect_deck` 的四个可选参数为 `detail_level`、`view_upgrades`、`sort_by`、`descending`。默认摘要；省略页面选项保持省略，新页面默认由游戏决定。错误类型、未知字段、非法枚举及无排序键的方向在发 IPC 前拒绝。支持重复调用并复用页面。`close_card_view` 无参数，显式返回下层页面，可能是地图或战斗。

两者属于改变 UI 的操作，标记 `readOnlyHint: false`、`destructiveHint: false`、`idempotentHint: false`；复用单控制锁和串行处理，发请求前清除旧令牌，成功、失败、超时及取消均不自动恢复或授权动作。关闭返回基础观察后，仍须显式 `get_observation` 才能行动。不自动重试、不在超时或取消时擅自关闭页面。

牌组响应逐层投影，校验场景、档位、布尔选项、排序、唯一的 `deck:` 标识、卡牌基础文字及费用；完整模式校验正文与附带解释。摘要即使收到额外正文也不转发。完整解释继续由文件客户端逻辑去重，以 `card_ids` 关联。关闭只返回基础观察字段，不转发牌组或控制元数据。

## 基线与验证关注点

游戏 Linux `v0.107.1` main commit `59260271`；Mod 0.10.0；Python 3.14.8、`mcp==1.26.0`，当前协议 `2025-11-25`，旧服务 0.6.0、七工具、73 项 Python 检查。本次只调用既有文件接口，不新增游戏 API。

重点：`false` 与省略不能混淆；布尔值不得误判成排序数字；无效参数不能触发 UI；重复调用不重新打开页面；关闭结果不能准备下一次动作；失败及取消不发送额外补偿动作；工具列表始终固定，不因牌组页打开而增删。正式验证结束时显式关闭页面，玩法数据应与浏览前相同、原始状态令牌应不同。

新增原生证据为 `.tmp/decompiled/NMapScreen.cs`、`NOverlayStack.cs`、`NCardPileScreen.decompiled.cs` 和 `NCapstoneContainer.cs`：地图独立于 capstone 卡牌页，返回按钮只关闭 capstone。Mod 0.10.0 增加 `screen.view` 标识当前卡牌页或剩余地图，并修正地图打开时基础观察仍可能读取战斗的边界。原始 `close_deck` 文件操作仅为兼容保留，不注册为 MCP 工具。原生 `CloseInternal` 无条件 `Unpause`，地图仍打开时也沿用原生人工按钮行为，不另行增加暂停计数；地图始终按 covered 拦截战斗动作。
