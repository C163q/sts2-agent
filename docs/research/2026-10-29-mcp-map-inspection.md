## 已确认设计

在既有 MCP server 中增加无参数 `inspect_map()`、`close_map()`，固定工具列表由 10 项增至 12 项，服务版本升至 0.9.0。复用已验证的 Mod 0.12.0 文件操作，JSON 契约以 [地图查看](../development/map-inspection.md) 为准，不新增地图参数或选路动作，不修改用户全局 MCP 配置。

两项工具会改变 UI，声明 `readOnlyHint: false`、`destructiveHint: false`、`idempotentHint: false`、`openWorldHint: false`。合法请求发送前清除旧动作令牌，成功、错误、超时和取消后均不恢复或授予动作权限。非法参数在 IPC 前拒绝，保留此前权限。现有串行锁、控制进程租约及错误脱敏继续适用，不自动重试或关闭页面。

地图输出只保留当前幕约定字段；校验整数、规范 ID 与坐标、节点及引用唯一性、连线引用、当前位置与已走路径、候选集合及其布尔状态。候选允许出现在当前节点连线以外；双 Boss、已揭晓问号和额外可见标记保持原义。过滤根和嵌套附加字段，不向 LLM 传递控制令牌、seed、未来配置或动作列表。关闭沿用已有基础观察投影并拒绝仍残留浏览页的成功响应。
