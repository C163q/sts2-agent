总流程见[工具清单](2026-11-02-mcp-tool-review.md)；源码、问题编号与测试依据单列在[开发核验](2026-11-05-inspect-rewards-development-notes.md)。

## 优先问题

| 问题 | 优先级与实际影响 | 建议 | 状态 |
| --- | --- | --- | --- |
| 拒绝原因过于笼统 | 中：非奖励场景、奖励被地图或选牌遮住、尚未就绪，都只显示“操作不可用”，不说明如何恢复 | 区分固定原因，提示先完成当前选择、关闭相应覆盖页或等待入场；保持纯读取的已有许可恢复 | 已核对源码并实测，待确认修复 |
| 矛盾的成功响应仍会被接受 | 中：响应声称奖励可见，却同时声称被地图覆盖、隐藏或未就绪，公开层仍显示内容并刷新操作许可 | 核对奖励详情与场景／画面状态一致；矛盾结果返回 transport_error，清除许可 | 合成损坏响应已验证；真实游戏未出现同类成功响应，待确认修复 |
| 旧奖励全流程验证器已过时 | 低：开启截图后仍要求工具总数为 43，当前为 44，会在领取验证开始前失败 | 修正目录断言，继续验证原来的领取／跳过行为 | 源码及目录探针确认，待处理 |

第二项是接收损坏响应时的保护缺口，不表示工具在正常游戏中能读取被遮住的奖励。本轮真实覆盖场景会拒绝；建议先补齐正确性与诊断，再增加输出参数。

## 已核对的正常行为

当前参数只有 `preset:default/full`，默认 default。工具不需要先调用 get_observation；它是纯读取，成功结果也可以支持下一步合法操作。

- 返回 `scene`、`screen` 和 `rewards`；没有 transition，也没有 available_actions。后者可从基础观察获取，不属于遗漏。
- `rewards` 包含状态、标题、当前全部可滚动奖励行和原生跳过／前进按钮。没有按屏幕滚动位置截断奖励行；真正隐藏的行或标签仍排除。
- 每行包含稳定奖励 `id`、`type`、可见 `text`、`enabled`、`linked_group` 和 `hover_tips`。full 保留普通 null；default 按统一规则过滤，空 hover_tips 当前保留为 []。
- 奖励 id 不是行下标、卡牌 id 或药水槽位；领取其他行后，剩余行的 id 保持。互斥组的 linked_group 是组身份，不一定对应某个可领取条目的 id。
- 只读取当前最上层奖励页；嵌套奖励打开后读取子页，返回后再读取父页。全部领完或无掉落时仍可读取空 items 与 Proceed 按钮。
- 悬停说明来自原生奖励行实际使用的提示。普通卡牌奖励尚未打开时不返回候选；追回指定卡牌的奖励可以提供其已公开的卡牌预览文字。
- 不生成、领取、跳过、重抽奖励，也不改变滚动位置。满药水槽不会因此自动用药或丢弃药水。

纯读取遇到明确非法操作时，已有操作许可会保留，错误的 recovery 为 choose_legal_action；首次读取失败则没有许可可保留，仍要求读取。旧状态、超时、损坏响应与异常沿用保守处理。因此这里没有此前动作工具的“拒绝后被迫重新观察”问题。

## 候选参数

建议在三项问题处理后，增加两个相互独立的选项，现有 default/full 保持：

| 选项 | 建议语义 |
| --- | --- |
| `preset:summary` | 沿用基础观察的奖励内容，只省略各行 hover_tips，保留标题、条目身份／文本／启用状态、互斥组及跳过／前进按钮；普通 null 沿用 default 规则 |
| `reward_ids` | 按稳定奖励 id 筛选当前页；省略或 null 表示全部，[] 表示不取条目，去重并维持原生列表顺序；未找到的 id 合并报告，其他有效条目仍返回 |

筛选只缩小返回条目，不替模型领取奖励，不改变 title 或 proceed，也不让隐藏奖励变为可见。每行已有 id，结果无需另加位置映射。筛选范围是当前最上层奖励页，不能用父页的 id 穿透查看子页背后的内容。

summary 已经等同于“查看静态奖励行，需要悬停说明时再用 default/full”；不需要缩写 text、合并奖励类型或丢掉 enabled:false。也可以只处理三个问题而暂不加参数；现有列表通常不长，新增参数主要用于聚焦某一项悬停说明。

## 典型 JSON 与范围

[9 份典型完整返回](2026-11-05-inspect-rewards-examples/README.md)覆盖普通混合奖励、互斥组、空列表、嵌套奖励、追回／逃脱和错误，其中八份 full、一份 default。不同奖励内容不要求各自提供重复结构的样本。
