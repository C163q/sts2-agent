## 优先问题

| 问题 | 优先级与实际影响 | 建议 | 状态 |
| --- | --- | --- | --- |
| 点击前明确拒绝会丢失已有操作许可 | 中：目标本来就不可选、地图未开或被牌组覆盖时，模型改用其他合法操作也被要求重新观察 | 明确没有交互且已有许可时保留；已滚动、已点击、旧状态及结果不明时仍要求观察 | 已实测，待确认修复 |
| 具体拒绝原因没有传给模型 | 中：未开地图、被覆盖、绘图模式、节点不可选都只返回“操作不可用”，模型无法判断如何恢复 | 区分固定原因，提示打开地图、关闭上层牌组或改选当前候选；不公开异常文本 | 已实测，待确认修复 |

这两项与已有错误处理 TODO 属于同类问题，建议随本工具提前修复，不新增 TODO。成功返回暂未发现需要增加字段或预设的依据。

## 当前参数与使用规则

```json
{"node_id":"map:1:2:3","preset":"full"}
```

- `node_id` 必填，使用当前地图的 `selectable_nodes` 中的精确 ID。地图查看结果直接提供该列表，基础观察中则位于 `map.selectable_nodes`。
- `preset` 仅有 default/full，默认 default；不支持 summary、max_steps、多节点或强制选路。default 使用统一空值过滤。
- 查看地图成功后可以直接选路；不要求固定先调用 get_observation。选择被拒绝后的许可丢失是上述缺口，不能当作合理的观察前置要求。
- 只选择当前已展开、可交互的单人地图。地图被牌组、弹窗或选牌界面覆盖时不穿透点击；绘图中、旅行中或动画未就绪时不能选路。
- 原生候选可能包含飞鞋允许的无连线节点，不能仅按 next 判断。工具不选择路径，不连续前进多个节点，也不自动领取离开房间时会放弃的奖励。
- 目标在屏幕外时，先原生滚动到目标再点击；不改写地图坐标或直接调用进入房间。

## 当前成功反馈

返回精简动作回执，不附送下一房间的完整内容。普通火堆、商店、宝箱或事件通常返回 action_completed；进入战斗返回 player_ready；入场效果需要选牌时返回 choice_required 和选择类型／状态。需要候选 ID 或具体房间内容时，再按需查看。

以下为真实火堆入场的完整 `full` 返回：

```json
{
  "scene": "rest_site",
  "screen": {"status": "visible"},
  "available_actions": [
    "choose_rest_option", "inspect_ui", "inspect_potions", "inspect_relics",
    "inspect_deck", "inspect_map", "inspect_rest_site"
  ],
  "transition": {
    "stop_reason": "action_completed",
    "complete": true,
    "events": []
  }
}
```

这里 events 为空不表示没有旅行：当前事件记录的是生命、物品、卡牌、战斗等可见变化，没有额外的“进入火堆”事件；scene、操作列表和完成原因已经表示到达。实测普通战斗入场记录能量恢复和抽牌；combat_started 用于同次动作中的战斗间交接，并非每次入场都会出现。不提前揭晓尚未进入的敌人或问号内容。

## 建议保持的部分

参数已经适合一次点击一个目标，成功结果也足够精简，建议维持 node_id 与 default/full。新增 summary 只会重复同一结果；改为完整观察则会把每次旅行变成大段房间详情，必要时现有查看工具已经可以提供。

建议只处理两项优先问题，并整理旅行前的可用性检查。滚动本身也是界面交互，不能把“尚未点击节点”等同于“界面完全没变”；如果滚动后失败，应继续要求观察。超时、旅行中断或入场异常不能自动重试。

## 典型 JSON 与验证边界

[10 份典型完整返回及来源](2026-11-05-travel-to-node-examples/README.md)保留实际参数、空值、事件和错误。九种已完成的 GUI 采样为：普通火堆、飞鞋跳线、战斗、入场选牌、商店、宝箱、问号、第二幕起点先古之民、双 Boss 的第二场。它们覆盖不同到达反馈；普通战斗和火堆还确认成功后可以直接继续合法操作。飞鞋无连线选路、次数消耗、未领奖励随离房消失，以及双 Boss 后续战斗均已核对。它们不表示穷举全部房间或遗物组合。

不修改正式 Mod，不提前实现候选方案。多人、第三方地图、所有入场效果、任意并发人工操作及自然完整 Boss 战不在本阶段实测范围。
