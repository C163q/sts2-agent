## 目标与设计

在游戏外提供 Python stdio MCP server，复用 `scripts/roundtrip_client.py` 的文件 IPC 和玩家观察过滤。对外只提供 `get_observation()` 与 `end_turn()`，不公开测试战斗创建入口，不增加游戏 API 或修改 Mod。首次验证使用独立游戏实例，不操作正式对局。

MCP server 保存最近一次显式观察的 `snapshot_id`，不向模型暴露令牌、会话和内部异常。每次 `end_turn()` 消耗令牌；成功结果包含新观察，但下一次动作仍须显式观察。状态过期、动作失败、超时和通信异常均不自动重试或自动刷新令牌。MCP 错误使用 `isError` 和英语结构化错误，恢复操作名适配为 `get_observation`。

同一进程串行执行调用，文件 IPC 的阻塞等待在工作线程运行。每个 IPC 目录仅允许一个 MCP 控制进程，通过 Linux 文件锁拒绝重复连接；该锁不阻止手动客户端或玩家操作，仍以游戏侧状态校验为准。使用官方 Python SDK `mcp==1.26.0`，记录依赖与安装命令；Mod 保持 0.3.0。
