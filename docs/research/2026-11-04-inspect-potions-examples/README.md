# inspect_potions 核验示例

对应[场景与问题审阅](../2026-11-04-inspect-potions-review.md)。共 17 份完整公开 JSON：10 份复用隔离游戏的真实响应，3 份依据当前实现整理，4 份本地参数／模拟传输结果。不是 17 次新的游戏实测。

来源、原调用参数、基线与 SHA-256 见 [manifest.json](manifest.json)。原调用省略 preset 的药水样本中，仅有数组空槽为 null，default 与 full 内容相同；文件名 full 表示展示完整结构，不改写原请求。模拟拒绝只验证公开格式和许可策略，不代表已在每个原生拒绝场景执行工具。

完整场景目录与每份 JSON 的链接统一维护在审阅文档，不在此重复。示例不含内部令牌、测试控制信息或本机路径；清单中的路径仅用于定位不入库的原始证据。
