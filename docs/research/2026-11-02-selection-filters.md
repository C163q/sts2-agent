# inspect_selection 按卡牌 ID 筛选

当前状态：已完成。共 3 项，已完成 3 项；参数、投影、文档、完整 Python 回归和六类游戏场景验证均完成，无剩余实施项。

## 契约

在现有 `preset: full/summary` 基础上增加可选 `card_ids`，参数校验、去重、原生顺序与 `inspect_hand` 一致。省略返回全部，空数组不返回任何卡牌详情；非法参数不请求游戏或清除已有动作许可。

筛选范围包含当前可浏览的 `selection.cards`、`bundles[].cards` 和已经展开的升级／附魔／变牌预览。比较按 `before.id` 筛选，命中时保留完整 `before/after`，随机结果继续为 `after:null`。当前可浏览结果页也允许筛选，不把 ID 存在等同于可以点击选择。

选择类型、状态、提示、数量限制、全部已选 ID、按钮、包 ID 和选择级附魔说明保持不变；包内卡牌可因筛选变为空列表。未命中的单张升级预览为 `null`，列表预览为空列表。full 的共享悬停提示只保留命中卡牌的关联；summary 沿用现有卡牌摘要。未知 ID 按请求首次出现顺序合并为顶层 `errors: [{"code":"cards_not_in_selection","card_ids":[...]}]`，有效结果照常返回，MCP `isError:false`。

底层仍无参数，先读取并验证完整详情再筛选，不允许用空筛选隐藏格式损坏，也不改变 UI、候选范围或原生状态令牌。隐藏选择的读取继续失败，不读取其他牌堆确定缺失 ID 的位置。Python 更新后须重连 MCP，无须替换 Mod。
