# 手牌预设与 ID 筛选验证

## 实现与边界

核对日期为 2026-11-01，基线提交 `c25cd36`；游戏 Linux `v0.107.1`、Mod `0.34.4`、RitsuLib `0.6.10` 的 `0.107.1` 兼容运行时保持不变。MCP 升至 `0.31.0`，默认仍为 42 个工具，截图配置启用后为 43 个。只有 `inspect_hand` 的参数和对应描述改变，未修改全局工具提示、其他工具的参数或游戏 API。

新增 `preset: full/summary` 和 `card_ids`。默认 full 与原有结果兼容；summary 仅投影当前身份、显示费用及特殊费用颜色、描边和不可用标记。不推断可打出性，不附送正文、稀有度、卡池或共享悬停解释；保留查看战场时仍适用的选择导航说明。

筛选省略表示全部，空数组表示空结果，重复 ID 去重，结果保持手牌顺序。无效 ID 按请求首次出现顺序合并为 `errors: [{code: cards_not_in_hand, card_ids: [...]}]`，其他命中牌正常返回；全部无效也保持部分结果结构，MCP `isError=false`。不存在、已离手、不可见统一处理，不推断其他牌堆的位置。参数非法仍返回整次 `invalid_request`。

实现仅在 Python MCP 层投影。底层文件 `inspect_hand` 保持无参数并返回全部当前可见手牌；MCP 先完整校验，再过滤卡牌、共享提示关联和数值 note。因此 summary 与空筛选也会请求当前状态，不能隐藏未命中卡牌的损坏响应。底层错误原样进入既有失败语义，不替换为缺失 ID。

复用现有 `_inspect` 的互斥、取消检查和原生状态令牌。成功空结果及带合并错误的读取也刷新许可；本地参数错误按地图参数规则保留旧许可，不发送 IPC。筛选不改变状态指纹，排队动作不能借用未来读取的许可，外部变化仍会导致 stale_state。完整契约以[手牌详情指南](../development/hand-inspection.md#参数与返回范围)为准。

- 默认/显式 full 兼容，原始数据不被修改，MCP 参数不转发到 Mod。

- 筛选顺序、重复 ID、共享提示裁剪、部分/全部无效 ID 的合并顺序及 `isError=false`。
- 空手牌、空筛选、选择导航 note、非法参数不发 IPC。
- 未命中卡牌格式错误仍使完整读取失败，清除许可；底层错误不重试。
- 详情后直接行动、真实外部变化过期、排队动作不能借用未来读取。
- 真实 stdio schema、参数派发、文本与 structuredContent 一致。
