# 先古之民、领取选择与遗物适配核对

## 基线与证据

核对日期为 2026-10-31。目标为 Linux 游戏 `v0.107.1`、分支 `v0.107.1`、提交 `59260271`，发布日期 2026-06-18。安装目录相对路径 `data_sts2_linuxbsd_x86_64/sts2.dll` SHA-256 为 `d13f3f150b1413b24c3a9c5575cdf5398dc74270877d55dec9a556dd8150bd03`。依赖 RitsuLib `0.6.10` 的 `0.107.1` 兼容运行时。Mod 交付版本 `0.25.0`，MCP `0.21.0`，观察结构 `10`。

## 原生房间与动作

- `AncientEventModel : EventModel`，`LayoutType.Ancient`。`BeforeEventStarted` 处理进入时治疗，Neow 另有生命数字动画；`GenerateInitialOptionsWrapper` 应用 ShouldAllowAncient，可能只提供前进。不能写死“必有三件可领取遗物”。
- `NEventRoom.SetupLayout/SetOptions/OptionButtonClicked`、`NEventLayout.AddOptions`、`NEventOptionButton.OnRelease`：选项点击经 EventSynchronizer 选择本地选项，保留历史和正常回调，不直接执行遗物发放。
- `EventSynchronizer._pendingOptionTasks` 保存原生选择任务。读取其完成状态即可阻止重复提交；不能等待整个任务后才输出，因为 `RelicCmd.Obtain` 可被选牌或 RewardsSet 暂停。
- `NAncientEventLayout.SetDialogueLineAndAnimate` 通过原生 hitbox 推进一句，最后一句才展开选项；不在观察时自动跳过。`NAncientDialogueLine` 的真实透明度和裁剪决定当前可读内容，不由模型的完整 dialogue set 补齐后文。
- `NEventRoom.Proceed` 打开当前地图并允许原生旅行；本项目仍只开放查看，不实现节点点击。
- `TheArchitect` 是独立 EventModel，并非这组常规 AncientEventModel，本次不开放终章事件操作。

## 选择页面

| 触发效果 | 核对类型与适配 |
| --- | --- |
| 佩尔之牙、剪刀等移除 | `CardSelectCmd.FromDeckForRemoval` → 既有 `NDeckCardSelectScreen`，多选与原生确认 |
| 放电异虾、三枚回旋镖等附魔 | `FromDeckForEnchantment` → `NDeckEnchantSelectScreen`，新增 `deck_enchant`；单张 `NEnchantPreview` 显示实际前后牌面，多张页只显示原牌，不能模拟出不存在的比较 |
| 新叶、星盘、利爪等变牌 | `FromDeckForTransformation` → `NDeckTransformSelectScreen` / `NTransformPreview`，新增 `deck_transform`；未知替换使用每0.2秒轮换的示意牌，禁用的预览 hitbox 可识别这种循环。归一化 `random:true, after:null`，不作为结果或行动候选 |
| 卷轴盒 | `FromChooseABundleScreen` → `NChooseABundleSelectionScreen` / `NCardBundle`，新增 `bundle`；`bundle:N` 按钮打开真实包内预览，可返回后重选，再确认整包 |
| 潘多拉魔盒 | 变牌已经完成后打开 `NSimpleCardsViewScreen` capstone，新增 `view_cards`，只提供原生确认，不再次选牌 |

附魔候选不足数量等情形由原生 CardSelectCmd 处理，不能强行创建页面。选牌与领取互相暂停时保留当前 UI 优先级；覆盖内容不读、不点击。

## 五种遗物机制

`WhisperingEarring.AfterAutoPrePlayPhaseEnteredLate` 在首回合按手牌序寻找可打出的牌，花费资源后自动打出，最多13张；使用 `VakuuCardSelector` 在原生阶段自动处理选择，不要求 MCP 再手动选择。它本身不请求结束首回合。注能 `Imbued.AfterAutoPrePlayPhaseEntered` 先于耳环的 Late 阶段触发。

`TouchOfOrobas.SetupForPlayer/AfterObtained` 关联起始遗物与升级版，调用 `RelicCmd.Replace`；不是任意选一个遗物替换。`ArchaicTooth` 类似地关联起始牌及固定升级替代牌；两者预先关联的内容已经在选项正文和 hover 展示，属于可读信息。

`PaelsEye.BeforeSideTurnEndEarly/ShouldTakeExtraTurn` 对未手动出牌的符合条件回合消耗手牌并获得额外玩家回合。自动出牌一般不计手动出牌；首回合拥有低语耳环另有排除。既有 `CanEndTurn` 和 TurnJournal 的原生回合开始事件可接住额外回合，无须等待虚构的敌人回合。

`PaelsTooth.AfterObtained` 通过可移除与可升级条件筛选；随后 `AfterCombatEnd` 从存储牌中随机取一张、升级、加入牌组并播放预览。本次真实测试发现战斗结束通知先于顶栏牌组数更新：返还后的模型6张，动作返回顶栏仍5张。修复后胜利边界等待原生战后预览/入堆飞行，并在新入牌组的牌实际可见时记录 `card_added`。选择边界仍及时返回，不等待依赖输入的父任务。

`ElectricShrymp` 用注能为技能牌附魔，战斗首回合由注能自身自动打出；实际效果、目标、卡牌触发和消耗均由游戏执行。

## 文本与信息边界

EventOption 构造时会缓存原游戏语言的 HoverTips，部分遗物还缓存 StringVar 中的牌名或遗物名。隔离中文游戏实际复现欧洛巴斯之触英语句子混入中文遗物名、悬停解释全中文。本次读取已公开动态引用，使用独立英语表格式化分离变量并重建对应 hover；不修改游戏语言、原变量、原缓存、选项结果或 RNG。

基础观察提供选项已展开的正文，详情才附悬停解释。名称横幅称号仅在实际显示时提供；隐藏和覆盖字段为 null。随机示意牌不用于猜测实际变化结果。独立游戏使用测试门控夹具，不会在正式对局中开放调试工具。

所有测试仅在目标版本实际单人隔离实例进行。尚未穷尽全部遗物组合、多人、特殊挑战、所有角色、第三方页面和其他游戏版本；不表示已经具备完整自动游玩能力。相邻场景回归及最终计数、截图和修复证据统一记录在 `.tmp/2026-10-31-ancients-report.md`。当前契约见[先古之民接口](../development/ancients.md)。
