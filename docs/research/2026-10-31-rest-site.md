## 原生流程

| 类型或成员 | 核实结论 |
| --- | --- |
| `RestSiteRoom.EnterInternal`、`RestSiteSynchronizer.BeginRestSite` | 进入房间时生成实际选项；`RestSiteOption.Generate` 明确可能推进随机数及改变状态，观察不得重新调用 |
| `NRestSiteButton.OnRelease/SelectOption` | 校验特有 `_isUnclickable`，禁用选项、调用同步器，成功后触发房间收尾；失败或取消后重新启用选项 |
| `RestSiteSynchronizer.ChooseOption` | 等待 `OnSelect` 返回；成功后记录历史，再清空全部选项或移除刚选项；失败不消耗机会 |
| `MiniatureTent.ShouldDisableRemainingRestSiteOptions` | 自己的选项执行成功后保留其余选项，不重复提供刚选过的同一项 |
| `NRestSiteRoom.AfterSelectingOptionAsync` | 等待隐藏选项与本地效果动画，重建按钮、显示前进，再淡入剩余选项；不能仅以生命变化判定完成 |
| `NRestSiteRoom.OnProceedButtonReleased` | 打开原生地图；未完成选择时按钮可能不可用 |
| `HealRestSiteOption.Description/OnSelect` | 说明包含实时恢复数值与遗物附加文本；恢复基础为最大生命的30%，实际数值受 Hook 修改；可追加奖励 |
| `SmithRestSiteOption.OnSelect` | `FromDeckForUpgrade`，可取消且须手动确认；无选择返回 false；确认后才实际升级及调用后置 Hook |
| `NDeckUpgradeSelectScreen` | 单牌显示升级前后，多牌显示升级后牌；`CancelSelection` 只退出预览并清空已选，`CloseSelection` 返回空选择，`ConfirmSelection` 才完成 |
| `CookRestSiteOption.OnSelect` | 从牌组选两张可移除牌，可取消；确认后原生移除并增加9最大生命 |
| `DigRestSiteOption.OnSelect` | 原生抽取并获取遗物，获得时可能触发嵌套选择或奖励；查看说明不预测结果 |
| `Girya/PumpkinCandle/MeatCleaver/Shovel` | 由实际遗物 Hook 添加选项；壶铃三次之后不再添加锻炼；填火增加南瓜蜡烛计数 |

因此采用两个新增工具和现有 `proceed`、选牌工具；不为每种选项复制工具。未知选项只查看，不自动执行。升级预览继续沿用候选原牌 ID，未显示的多牌升级前内容保持未知。

## 检查与图形证据

完整 Python 检查189项通过，包含新增输出投影、覆盖泄漏、预览身份、非法参数消费许可，以及真正子进程 stdio 路由；C# 停止条件/缓冲检查22项通过，Mod 构建零警告零错误。原有两处工具目录检查及一个无参数工具检查随新增工具更新，初次失败均为旧列表断言。

隔离中文图形游戏通过实际 stdio MCP 完成以下10类场景。证据均位于 `.tmp/2026-10-31-rest-site/`，每个 `*-first.json` 包含调用及返回，同行目录保存截图；运行参数为 `--rest-scenario <场景>`。

| 场景 | 核对内容 |
| --- | --- |
| `basic` | 地图覆盖隐藏内容、关闭后重观察、休息30→54生命、选项消失、前进打开地图 |
| `smith` | 打开升级列表、原生前后预览、取消预览、取消整个选择且保留机会、再次选择并确认升级 |
| `multi` | 两张升级预览保留原牌ID，不提前修改实际牌；取消与最终确认升级两张 |
| `cook` | 两张牌移除预览、取消不改牌组、确认后牌组减少两张且最大生命80→89 |
| `tent` | 壶铃、填火、休息依次执行，剩余选项保留且已选项移除，提前前进仍走原生地图 |
| `disabled` | 没有可升级牌、可移除牌不足两张，说明可读，点击被拒绝且不改变实际牌组 |
| `dig` | 原生挖掘获得一件遗物 |
| `heal_rewards` | 捕梦网追加卡牌奖励、打开奖励选牌后跳过，奖励页前进后恢复休息处流程 |
| `dig_nested` | 隔离夹具用原生 `TestRngInjector` 固定 Calling Bell；挖掘停在三件嵌套奖励，跳过后回休息处，无大卡预览继续遮挡 |
| `dig_choice` | 同一夹具固定 Astrolabe；未接通的变化选择返回 `manual_input_required`，无动作许可，不等待超时 |

多牌升级夹具在进入后将原生 SmithCount 设为2，只验证原生多牌流程；不是证明某个正式遗物必然提供两次升级。测试入口均受 `STS2_AGENT_TEST_MODE` 与专用场景变量限制，不注册为 MCP 工具，不能用于正式对局。独立审阅未发现有证据的产品问题。

未穷举所有遗物 Hook、复制/孵化选项、第三方选项或多人修补目标流程；没有实现地图节点旅行。隔离加载与行为验证不代表已在用户当前正式对局重新加载新 DLL。
