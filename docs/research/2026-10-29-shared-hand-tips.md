# 手牌共享悬停解释

核对日期：2026-10-29。范围为客户端玩法 JSON 的输出整合，复用 Mod `0.4.0` 的逐牌原始响应，不修改游戏 API、Mod 或 MCP 配置。游戏基线仍为 Linux `v0.107.1`，提交 `59260271`。

## 输出规则

- `hover_tips` 与 `hand` 平级，每张牌不再内嵌提示。
- 标题与正文同时相同才合并；同标题而正文或动态数值不同的条目分别保留。
- 条目按首次出现顺序排列，以 `card_ids` 记录关联手牌，同一关联 ID 不重复；卡牌 ID 与顺序不改变。
- 原始响应不改写，`--raw` 保留逐牌提示；未知牌不生成提示条目，空手牌保留两个空数组。
- 数值说明的适用范围不变，详情结果只提供 `notes.card_values`。

实现与调用契约见 [手牌详情 JSON](../development/hand-inspection.md)。
