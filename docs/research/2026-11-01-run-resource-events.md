## 实现与边界

`GameAdapter.Resources.cs` 包装当前全部 21 个游戏动作；`ActionEventScope` 为单次请求提供一个有界缓冲，战斗、药水与资源记录器共用序列。返回成功时把该缓冲附入已有 `transition`，保留停止原因、原始状态令牌和原生业务结果；错误和没有 `transition` 的读取响应不改写。512 条上限统一作用于全部来源，截断令 `complete:false`。作用域及订阅在正常返回、错误或异常后释放。

`RunResourceJournal` 仅订阅本地玩家，检查实际顶栏及对应数字标签；金币保存已知公开基线，隐藏时清除，恢复后不补写隐藏变化。最大生命和金币新增专用类型，战斗外 HP 沿用 `hp_changed`。已有战斗记录器工作时由它负责 HP，以免同一伤害另被资源采集器重复记录。

原生选择完成源可能先结束，旧选择页稍后才移出覆盖栈。资源采集只在没有仍有效的当前选择、顶栏实际可见且仍处于已核实原生选择页的这段交接中放宽页面门控；地图、capstone、卡牌／遗物详情、过渡和模态遮挡仍排除，数字标签仍须可读。

从事件或地图进入战斗后，`CombatEntryCapture` 创建的 `TurnJournal` 继续引用同一缓冲，资源事件不会被新的战斗记录覆盖。当前事件来源仍只提供已经核实的来源；战斗外扣血只表达 HP 改变，不从正文推断伤害或来源。

Python 沿用 `game_output.EVENT` 的 `target/before/after` 投影，为新增类型补充玩家身份、非负整数及必填字段检查，布尔、字符串、缺失或未知值均不能通过。精简动作回执保留全部已验证事件，既有许可、等待和重试规则不变。
