## 已确认设计

为 `inspect_relics` 增加 `preset: full/summary` 和 `relic_indices`。默认 full、未传筛选时保持原返回；summary 的遗物条目只保留基础观察已有的 `name/counter/melted`，不含正文、共享解释或隐藏计数。沿用原调用当前可见且可悬停的范围，不扩大为其他遗物。

现有遗物没有稳定 ID，参数使用未筛选 `inspect_relics` 列表从 0 开始的下标，不冒充持久标识或基础观察的下标。省略筛选返回全部，`[]` 返回空列表；去重并保留原生顺序。传入筛选时附顶层 `relic_indices`，与返回 `relics` 一一对应，指向未筛选列表的位置。full 的 `hover_tips[].relic_indices` 继续指向本次返回数组，筛选后须重新编号。

下标为 0 至 2147483647 的整数；拒绝布尔值、浮点数、字符串、`null` 和未知参数，不请求游戏或清除旧许可。超出本次可读列表范围的下标，按请求首次出现顺序合并为 `errors:[{"code":"relic_indices_out_of_range","relic_indices":[...]}]`，有效结果照常返回，MCP `isError:false`。不查询隐藏遗物、模型库存或其他页面。

先读取并验证完整原生详情再筛选，不用 summary 或空筛选隐藏坏数据。成功读取刷新动作许可，原生失败保持顶层 `error`。下标只对当前列表有效，遗物增减、排序及可见性改变后应重新读取完整列表；筛选结果中的位置不能直接当成原列表位置。
