# Cursor 下的模型选择

仅在当前会话运行于 Cursor，且可以选用或指定 subagent 模型时适用；用户当场点名其他模型时以用户为准。

- **默认推荐：Grok 4.7 High Fast** — 能力较强、成本适中，作为日常实现与中等复杂度任务的首选。该模型中文表现较弱，与其交互（含 subagent 的 `prompt`）应优先使用英语；面向用户的最终回复仍可用中文。
- **简单任务：GLM 5.3 Flash** — 能力较弱，但成本低、速度快，适合窄范围查询、格式整理、机械性改动等低风险工作。若当前会话无法选用该模型（例如 subagent 名单拒绝该 slug），回退为 **Gemini 3.8 Flash**。
- **较难任务：Claude Opus 5.5 Medium** — 当前可选模型中能力最强，适合架构取舍、跨系统设计、疑难排错等高风险或高复杂度工作；成本较高，不要默认滥用。
