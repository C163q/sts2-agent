# Codex subagent 模型选择

适用于当前会话运行于 Codex，且使用 subagent 的情况。用户当场指定模型或推理强度时，以用户要求为准。

## 独立选择模型

当 `fork_turns: "none"` 时，遵循以下选型规则：

| 任务 | 模型选择 | 建议推理强度 |
| --- | --- | --- |
| 一般任务 | 优先使用当前可用的最新 sol 模型，例如 `gpt-6.1-sol` | `high` |
| 简单任务 | 可以使用当前可用的最新 luna 模型，例如 `gpt-6-luna` | `high` |

简单任务包括窄范围查询、格式整理和机械性文档改动等低风险工作。模型标识仅为示例，实际选择当前会话可用的同系列最新型号。通过 `model` 指定模型，通过 `reasoning_effort` 指定推理强度。

使用 `fork_turns: "none"` 时，应在任务说明中提供完成工作所需的上下文，以便子代理在独立会话中完成工作。

## 继承父会话

当 `fork_turns: "all"` 时，子代理继承父会话的模型与推理强度；该模式仅使用继承配置。
