# 游戏观察的信息边界

本项目以还原玩家操作和 UI 反馈为目标。本文定义允许提供的信息；实际字段、参数、空值和输出预设由[开发与接口文档](development/README.md)维护。基础观察见[游戏基础观察 JSON](development/observation.md)，当前兼容基线见[项目 README](../README.md#当前版本与前提)。

## 当前画面与身份

- 以采样时已展开的界面为准，提供可见文字、数字、对象外观、图标、计数、牌序、按钮和显示状态。除下述展开卡牌的完整格式外，未展开、被遮挡、未悬停的信息不自动补齐，也不自动打开其他页面。
- 允许把外观可识别的对象转为准确名称，并用模型身份及游戏本地化资源核对；不要求名称本身已作为画面文字出现。不能借身份附送未展示效果、隐藏对象、未来动作或随机结果。
- 已识别卡牌可提供固有类型、稀有度与实际外观卡池；未知或锁定卡牌不补真实身份。半隐藏手牌可提供名称、费用、位置、外框、已显示附魔图标和 Affliction 覆盖外观，正文及效果解释由专门查看提供。
- 基础观察的标准卡牌统一提供不含正文和悬停解释的牌面信息，full/default使用face_full/face_default，summary使用共用摘要；专项详情提供完整牌面，见[共用卡牌格式](development/hand-inspection.md#共用卡牌格式)。比较保留各侧身份和上下文，未揭示信息不由格式化补出。
- 图标不能静默丢弃；可返回图像或已核实的可见语义，无法确定时保留未知。可见附魔只提供身份、实际显示计数与置灰表现，不借内部数值补齐。
- 遗物图标的置灰、激活发光和熔化分别读取实际着色与 shader；不从内部触发准备旗标推断图标状态，字段及精简规则见[遗物详情](development/relic-inspection.md#格式)。
- 可见生物按真实阵营记录；共享格挡不当作额外资源。充能球保持原生队列和空槽，悬浮君王之剑只提供可见身份，悬停细节通过相应查看工具提供。
- “看不见”与 0、false、空集合不同。仅在已核对 UI 规则时进行无信息增益的归一化，例如正常显示且无遮挡的生命条没有格挡标记可表示无格挡。
- 英语输出不切换游戏语言；数值取实际显示内容，不主动刷新 UI、重算目标预览或模拟效果。不能将已有修正的预览数字重复应用同一修正，具体数值说明见[观察文档](development/observation.md#数值预览说明)。

## 可浏览列表

当前已展开页面的可浏览列表或文字一次完整读取，包括玩家可通过滚动、平移查看的区域；保留原生顺序、筛选／升级模式和已揭示状态，不要求 LLM 逐屏滚动。适用于选牌候选、奖励、显式打开的牌组／牌堆／地图，以及原生本局详情的滚动内容。

滚动区域外与隐藏内容不同：整页被覆盖、控件隐藏／透明、未揭示牌面、未来选项或后续解锁仍不读取。非浏览区域的战场对象身体及入场动画继续按实际显示判断。已展示的战斗状态、意图、充能球及悬浮剑等附属图标与标签不按视口坐标截断，隐藏、透明或实际裁剪的内容仍不补齐；详见[战斗对象边界](development/combatant-inspection.md#读取边界)。药水槽位与图标不按视口位置截断，隐藏及不可悬停时的返回见[药水边界](development/potion-inspection.md#显示与悬停边界)。遗物栏不按视口位置截断，具体图标、可悬停明细和持有总数的区别见[遗物边界](development/relic-inspection.md#读取边界)。

商店已展开商品及价格标签不按视口坐标截断，真正隐藏、透明或被父控件裁剪的内容仍排除；实际点击和可悬停说明分别判断，见[商店边界](development/shop.md#打开观察与详情)。

完整读取不意味着可直接点击画外对象；动作仍沿原生滚动定位、状态复核和合法性检查执行。这项规则不自动增加工具尚未实现的浏览主体，不授权读取真实抽牌顺序、未打开页面或隐藏历史。

## 专门查看与场景边界

| 界面 | 信息边界及现行接口 |
| --- | --- |
| 手中卡牌 | [手牌详情](development/hand-inspection.md)显式提供正文及共享悬停解释，沿用基础观察的稳定 ID |
| 界面与战斗对象 | [界面帮助](development/ui-inspection.md)、[生物、充能球与悬浮剑](development/combatant-inspection.md)仅提供当前可见且原生可悬停对象的说明；不读后续招式 |
| 药水与遗物 | [药水详情](development/potion-inspection.md)保留槽位，full/default 固定提供一份通用槽位帮助；[遗物详情](development/relic-inspection.md)不附送风味文本或隐藏计数 |
| 牌组与牌堆 | [牌组](development/deck-inspection.md)、[战斗牌堆](development/pile-inspection.md)真实打开原生页面；已打开牌组／牌堆的基础观察仅给静态牌面，正文与解释由专用工具提供；抽牌堆只返回原生展示顺序，空堆保留真实反馈 |
| 地图 | [地图查看](development/map-inspection.md)只读当前幕；已走路线和当前候选与绘制连线分别表达，不提前揭晓问号或其他幕 |
| 卡牌选择 | [选牌](development/card-selection.md)保留当前模式及实际展开的比较；眼睛与覆盖页隐藏候选，不自动切换视图，随机轮换预览不当作确定结果 |
| 奖励、休息处与宝箱 | [奖励](development/rewards.md)、[休息处](development/rest-site.md)、[宝箱](development/treasure.md)只提供当前已展示内容；未打开奖励候选、未开箱宝藏及挖掘结果不提前公开 |
| 商店 | [商店](development/shop.md)只在商品页已展开后读取库存；基础观察不提供卡牌正文，完整效果由详情调用提供，不暴露假商人隐藏身份 |
| 事件与先古之民 | [事件](development/events.md)、[先古之民](development/ancients.md)提供当前已展开正文与选项，悬停解释单独查看；不提供后文或领取结果 |
| 占卜 | [占卜](development/divination.md)将实际已揭开图案转为文字部位，支持可选棋盘图像；隐藏、透明与格线遮挡区域不补齐身份、内部物品分组或未来奖励 |
| 终章与结算 | [终章](development/run-ending.md)只提供当前完整气泡和已显示结算内容；发现提示保留原生数量限制，不提前透露后续解锁，胜负以原生结算为准 |

`available_actions` 表示当前公开工具的可用范围，与具体参数是否合法分别判断；它不附送候选参数或保证未来状态。完整定义见[基础观察](development/observation.md#玩法字段)。

## 动作期间事件

游戏动作可在独立 `transition` 中返回提交至停止边界之间实际发生、已经公开的变化，统一字段和限制见[期间事件契约](development/end-turn.md#事件语义)。普通观察不回放事件，`complete` 也不承诺穷尽所有机制。

记录以变化期间的真实展示为边界，不因可浏览列表规则而补记隐藏历史；恢复可见后不回放隐藏区间，不由选项正文推算资源端点、未展示身份、牌堆位置或未来结果。事件只提供契约允许的变化类别与已公开字段，不自动展开牌面或悬停正文。

## 采样与控制信息

一次观察的画面和结构化内容须对应同一采样状态。截图和请求间若有悬停、焦点或动画差异，须说明差异，不能把另一时刻的内容补入本次观察；顺序调用不是原子快照，见[截图边界](development/screenshots.md#画面与动作边界)。

请求 ID、令牌、会话、去重信息及定位对象所需的 ID 属于通信或控制元数据；面向 LLM 时与玩法内容区分，不能借标识携带隐藏规则或未来结果。调试覆盖层、种子等内部信息不进入玩法观察。

源码、知识库、历史记录或 LLM 自身记忆可用于核对与决策，但不得把这些来源的额外结论伪装成本次直接观察。几何可见性目前不是任意 Mod 图层的逐像素遮挡判定，实际限制见[采样说明](development/observation.md#采样与验证)。
