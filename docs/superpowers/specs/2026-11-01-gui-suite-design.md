# 图形测试进程与对局复用

默认一个套件启动一个隔离图形游戏进程，用例之间经原生返回主菜单流程结束旧局，再配置并创建新局。只有清单中显式连续的同局步骤保留当前局；步骤不能重新构造或重置场景。失败停止套件，不把失败后的进程交给其他用例，也不自动重试未知结果的动作。结算、历史和解锁用例继续使用原有独立进程及存档。

Python 套件负责独占测试目录、启动/关闭自己创建的游戏进程、执行已有验证脚本、逐例归档日志/截图/请求结果，记录 PID、游戏会话、局身份及配置/创建/执行/清理耗时。测试目录与正式游戏、已有手动测试实例隔离。使用同一局的步骤显式共享游戏状态；MCP 默认逐例重连，不复用上例观察许可，测试每一步仍要按公开接口取得观察。

Mod 仅在测试模式及套件标志同时启用时接受动态场景配置、清理和局身份查询；不增加公开 MCP 工具或改变玩法 JSON。场景参数使用白名单，复用现有夹具；场景通过每局配置读取，不改写进程环境变量。新局清理同时释放夹具任务和测试补丁；不能确认清理完成就拒绝复用。保留原有单用例启动方式。

首批迁移连续动作、选牌连续动作、休息处、商店、奖励和宝箱等代表性验证，并新增同局连续步骤。通过同一 PID 下不同局身份、同一局身份下不同步骤、取消中选牌后的清理、补丁不污染后续测试和失败不继续执行验证隔离。记录实际启动次数和耗时；不承诺固定提速倍数，不将同进程新局等同于全新存档。

基线为 Linux 游戏 `v0.107.1`（`59260271`）、RitsuLib `0.6.10`、Godot `4.5.1`。已核对本地游戏程序集反编译的 `NGame.ReturnToMainMenu/StartNewSingleplayerRun` 与 `RunManager.CleanUp`：原生流程重置动作队列、选牌、覆盖页、战斗和网络同步器。证据分别位于 `.tmp/decompiled/MegaCrit.Sts2.Core.Nodes.NGame.decompiled.cs` 和 `.tmp/decompiled/RunManager.cs`；仍需真实图形验证任务取消及跨局残留。
