# 终章与结算设计

## 范围

接通 v0.107.1 的建筑师终章、胜利问号与死亡结算、必要解锁和返回主菜单。单人原生流程；测试实例与正式游戏、存档隔离。现有自主执行授权适用于接口决策与验证，不另设设计批准步骤。

## 接口

- `scene: epilogue`、`epilogue`：当前可见的说话者、完整当前台词和继续/前进按钮。复用 `advance_dialogue` 与 `proceed`，一次操作只前进一页。禁止读取未来台词、访问次数或随机分支。
- `scene: run_result`、`run_result`：阶段、实际可见文本、分数行、徽章、发现数量、可点击按钮。初始页不提前展示第二页内容；被其他界面遮挡时不透出底层内容。胜利保留界面的问号，不把脚本中玩家死亡误报成失败。
- `inspect_run_result()`：当前页的详细说明，包括徽章、发现图标的原生悬浮说明；发现列表遵守原生最多十项的显示限制，不读取完整存档。
- `run_result_option(option_id)`：只点击当前观察提供的按钮或待揭示解锁条目。覆盖继续、查看本局、返回、时间线揭示、解锁确认。返回稳定的下一输入界面；不自动跳过任何页面，不将正常游戏中任意菜单当作结算操作入口。
- 成功动作沿用快照令牌复用；查看详情不刷新令牌。界面切换、阶段与对象代数均参与过期检查。拒绝额外参数、不合法 ID、被遮盖按钮以及重复请求。

## 实现约束

原生按钮点击、原生事件同步器、原生结算保存和菜单切换；不得通过直接调用结束一局或修改存档代替玩家操作。游戏线程读取与执行，异步等待不阻塞渲染。初始化、打字、结算计分、解锁动画期间不报告就绪；超时保留未知结果。观察以屏幕节点为主，仅用当前节点绑定的本地化来源恢复英文，不重新抽签或重新计算累计伤害。

## 验证

Python 边界测试涵盖各阶段、隐藏信息、参数与令牌；C# 编译及现有纯逻辑检查。隔离图形实例验证建筑师至胜利两页、战斗/事件死亡、解锁后返回菜单；截图与公开 MCP 输出逐页比对，保存原始证据。不得操作正式游戏来建立测试场景。编译不作为正式游戏已重启加载的证据。
