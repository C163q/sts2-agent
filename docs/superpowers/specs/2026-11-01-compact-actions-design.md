# MCP 动作结果精简

## 范围与输出

MCP 的全部游戏动作统一返回精简回执：`scene`、`screen`、`available_actions`、原有完整 `transition`。存在选牌时仅附 `selection.type/status`；只保留当前选牌和人工输入所需的 `notes.selection/interaction`。购买和领奖的 `purchase_result/reward_result` 属于动作结果，继续返回，防止把原生购买失败或未获得误报为成功。

动作不再附送玩家、敌人、顶栏、候选牌、升级预览、商店库存、事件正文、结算详情或占卜图像；无关空字段省略。调用方按需使用 `get_observation` 和专项查看工具，不能把事件记录当作完整状态差量。`end_turn` 使用同一规则，下一回合手牌和敌人意图按需读取。参数、工具数量、错误结构、普通观察和查看页面工具保持现有契约。

## 实现与约束

只在 `GameTools._action` 返回前投影已经完成完整验证的公开结果。完整观察、图像验证、取消检查、状态令牌与许可续接全部先执行，精简不改变等待稳定、动作授权、过期拒绝或信息边界。使用普通字典返回，避免无棋盘 JSON 却仍附送图像。保留购买和领奖结果的既有校验。

MCP server 升为 `0.28.0`，文件 IPC 和观察 schema 保持 `16`。图形回归另外确认升级选择取消预览时，原生网格卡牌描边的 0.5 秒淡出会在原有 0.25 秒静默等待后才改变观察；返回休息处时，原生说明文字也会以 1 秒淡出，导致下一动作过期。Mod 升为 `0.33.0`：选择边界等待当前可见网格卡牌的有限 `NCardHighlight._curTween` 完成，休息处就绪条件补查 `_descriptionTween`，不等待父选择任务或循环装饰；未知选择不增加此等待。安装后完整重启游戏，并重连 MCP。
