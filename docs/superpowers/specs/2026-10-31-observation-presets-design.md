# 观察预设与当前可用工具

## 范围与语义

适用于 Linux 游戏 v0.107.1、RitsuLib 0.6.10。`available_actions` 返回当前可用的公开 MCP 查看与操作工具名，不含参数，省略始终可请求的 `get_observation` 和可选截图工具，也不包含测试入口。列表不保证任意参数有效或后续状态不变；具体调用仍核对参数、页面、原生可操作性与状态令牌。未知界面不提供底层操作。

现有实现从实时游戏状态生成动作列表，但未列出详情、关闭页面及选择视图切换工具，Python 又按动作白名单过滤。此次沿用游戏端判断为来源，补全详情和页面工具，提取共享可用性条件，防止列表与调用入口分歧；不以静态场景表猜测原生按钮。

## 输出预设

`get_observation({"preset":"full"})` 是默认行为，无参数与空对象兼容。`actions_only` 读取并验证同一完整观察后，仅投影 `scene`、`screen`、非空 `selection` 的 `type/status` 以及 `available_actions`。`scene` 保留现有房间/战斗语义；`screen.view` 区分地图、牌组、占卜、确认与结算；选牌状态区分候选页、查看战场、被覆盖和不支持。没有选牌时省略 `selection`。

精简模式不返回参数候选、牌面、生命值、地图节点、提示或图像，不改变游戏界面，也不持久化为后续动作的输出模式。完整动作结果仍使用完整输出。两种预设均刷新内部状态令牌；隐藏字段不参与模型输出。参数只允许可选字符串 `preset`，取值为 `full/actions_only`；非法参数返回 invalid_request 并清除动作许可，不发送游戏请求。

## 可用工具核查

- 详情调用与真实入口共用当前可见性、单人及就绪条件，不能穿透选牌、地图、确认或结算读取底层信息。
- 选牌候选页提供 `inspect_selection` 和原生允许的选择、按钮与眼睛；查看战场后仅提供真实可用的查看工具、页面工具及返回选牌。
- 地图与牌组/牌堆页面提供可执行的查看、替换或关闭工具；不保留底层出牌与结束回合。
- 房间详情和动作遵循各自原生入口。结算详情与按钮、事件确认等维持专属边界。
- Python 接受公开工具白名单并去重；动作结果的失败/超时不恢复动作许可。列表中增加详情工具不得弱化结算、地图和弹窗的输出校验。

## 验证

先验证默认兼容、精简上下文、无图片及敏感字段、非法参数、令牌续接和失败恢复，再通过隔离游戏的真实 MCP 检查普通战斗、手牌选择、查看战场、地图、牌堆、各房间、确认与结算。已列出的无参数详情/关闭工具应在对应页面可成功调用；有参数工具以至少一种合法调用或当前原生候选为证据。不操作正式对局。完成 Python 全套、C# 检查、编译、文档同步、独立审阅及 Git 提交。
