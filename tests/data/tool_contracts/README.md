# 工具行为固定样本

这些固定输入与期望值属于 [2026-11-03 重构计划](../../../docs/superpowers/plans/2026-11-03-tool-architecture-refactor.md)的第一阶段基线，提取自提交 a9eb4d7 的公开输出。它们是既有单元夹具的合成响应，**不是本次游戏实测**；状态令牌统一替换为 fixture-state。

states.json 复用各场景原生输入，expected.json 去重保存固定期望值；cases.json 固定 42 个玩法工具的成功、原生拒绝、本地参数拒绝、default/full 和已有专用预设，以及槽位、部分筛选、事件方向与 null、共享提示和占卜媒体。cli_cases.json 另固定 51 组文件客户端的默认值、完整状态范围和已有预设。用固定期望回放，不在测试运行时调用生产代码生成期望。

固定文件保留原始基线；经授权改变的接口在回放测试中以明确的局部差异核对，新增能力由专项测试覆盖。例如遗物提示引用原位置、summary 原生级别，以及 close_card_view 的 actions_only 返回。牌堆 opened 的 summary 省略底部固定 message；empty／unavailable 反馈仍保留。牌组的空原生参数统一为 null，与空对象同样表示省略选项。不得把已批准差异扩展成对其他工具的豁免。

改变期望值前须核对对应接口要求并说明差异；不能因为重构后的输出不同就批量重新生成。缺少的自然动画、真实禁用控件及跨房间 GUI 分支在后续原生阶段补采，不用本样本声称覆盖。
